Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Ensemble de pages et de ressources accessibles sur Internet grâce au protocole HTTP.

Internet

réseau mondial d'ordinateurs qui connecte des millions d'appareils à travers le monde.

Cloud

Service informatique fourni via Internet, permettant de stocker, gérer et accéder à des données et des applications sans avoir à posséder les infrastructures matérielles.

W3C

Organisme international qui définit les normes pour le développement du web, notamment le HTML, CSS et JavaScript.

Partie 2 - Distinguez les langages du Web

Langages client

Langages utilisés directements dans le navigateur de l'utilisateur pour créer et rendre interactives les pages web.

Navigateurs

Programmes informatiques permettant d'accéder et d'afficher les pages web sur Internet.

Langages serveur

Langages utilisés sur le serveur pour traiter les requêtes des utilisateurs et générer les réponses.

Frameworks

Ensemble d'outils et de règles qui facilite et accélère la création d'applications.

Bases de données

Ensemble de données structurées stockées sur un serveur et accessibles via des langages de requête.

Site responsive

Site web qui s'adapte automatiquement à la taille de l'écran de l'appareil utilisé pour le consulter.

Application mobile

Application informatique conçue pour être utilisée sur des dispositifs mobiles, comme les smartphones et les tablettes.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Ordinateurs ou programmes qui reçoivent et traitent les requêtes des clients sur un réseau.

Adresse IP

Adresse unique attribuée à chaque appareil connecté à un réseau, permettant d'identifier et de communiquer avec ces appareils.

Nom d’hôte et DNS

Nom utilisé pour identifier un appareil sur un réseau, et système de nommage qui permet de traduire ce nom en adresse IP.

Protocoles

Ensemble de règles et de conventions qui régissent la communication entre les appareils sur un réseau.

Partie 4 - Identifiez les métiers du web

Développeurs

Professionnels de la création et de la maintenance de logiciels et applications web.

Product Managers et chefs de projets

Professionnels responsables de la gestion et du développement de produits numériques.

Designers

Professionnels chargés de concevoir l'interface utilisateur et l'expérience client d'un site web ou d'une application.

Testeurs

Professionnels responsables de la validation et du test des applications web pour garantir leur qualité et leur fonctionnalité.

Techniciens informatique

Professionnels chargés de la maintenance et de l'administration des systèmes informatiques et des réseaux.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Langage de style pour embellir les sites web.

JavaScript

Front-End

Langage de programmation pour ajouter de l'interactivité aux sites web.

JavaScript

Back-End

Langage de programmation pour développer le backend des applications web.

PHP

Back-End

Langage de programmation pour développer le backend des applications web.

Java

Back-End

Langage de programmation utilisé pour créer des applications web, des services côté serveur.

Python

Back-End

Langage de programmation simple et polyvalent, utilisé pour le web l'automatisation, l'analyse de données et l'intelligence artificiellle.

C#

Back-End

Langage de programmation créé par Microsoft, utilisé pour développer des applications, des services web et des jeux vidéos avec Unity.

SQL

Bases de données

Langage utilisé pour créer, consulter et modifier des données dans une base de données.

Boîte à outils du développeur

  • IDE comme VS Code : Logiciel qui permet d'écrire, éxécuter et déboguer du code. VS code est par exemple un IDE populaire chez les développeurs.
  • Github : Plateforme qui permet de stocker, partager et gérer des projets et du code en ligne.
  • Librairies / bibliothèques : Ensemble de codes déjà écrits que l'on peut utilisier dans un programme pour gagner du temps dans le développement.
  • Frameworks : Ensemble d'outils et de règles qui facilite et accélère la création d'applications. En voici 3 exemples : Django (Python), React (Javascript), Spring (Javascript)
